# Windows release build — чек-лист (PRO-111)

Цель: доказать, что preset `Windows` даёт самодостаточный `Outadapt.exe`, и зафиксировать, что проверено, а что нет.

## Как собрать

Из корня репозитория (Git Bash / WSL / Linux-подобная оболочка):

```bash
GODOT=<путь к консольному Godot 4.7.2> bash godot/tools/export_win.sh
```

Требуется: Godot 4.7.2 и установленные export templates 4.7.2. Результат: `build/win/Outadapt.exe` (~130 МБ, PCK встроен, `build/` в `.gitignore`). Скрипт сам делает `--import`. Пути `D:\`/`E:\` не нужны.

## Найденное и рекомендации

1. **Иконка exe.** В preset не задан `application/icon`, exe получит стандартную иконку Godot. Нужна иконка до публичного демо (M3).
2. **Метаданные exe.** `application/modify_resources=false`: версия, название, copyright в свойствах файла не прописаны. Для их записи нужен `rcedit` (настройка Godot); решить до релиза.
3. **Подпись.** exe не подписан, SmartScreen покажет предупреждение. Подпись — задача M4.
4. **Имя пользовательских данных.** Каталог `user://` берётся из `config/name`; в `%APPDATA%\Godot\app_userdata\` уже есть папки старых названий проекта («Рой эволюционирует», «TD Prototype»), новая сборка пишет в `Outadapt`. Сохранения старых версий не мигрируют.
5. **MSAA 2D** в `gl_compatibility` не поддерживается — убрать настройку или принять предупреждение.
6. **`godot/run.bat` и README** содержат путь `D:\Godot`; для сборки он не нужен, но для новых разработчиков стоит перейти на `GODOT=`.
7. Старый `build/win/RoyEvolves.exe` (из прежнего имени проекта) лежит локально вне git; удалить вручную.
8. macOS preset здесь не проверялся.
